# HWPX 조판 규칙

## 플레이스홀더

수정 지점은 아래 형식의 문자열로만 지정한다. 프로그램이 문자열을 그대로
찾으므로 문서 해석이 필요 없다.

```
{{<TAXON>_<SLOT>}}
```

| 슬롯 | 용도 |
|---|---|
| `SPECIES_TABLE` | 종목록 표 |
| `RESULT_TEXT` | 조사결과 설명 문장 |
| `DIVERSITY_GRAPH` | 다양도 그래프 |
| `PHOTO_PLATE` | 사진대지 |
| `PROTECTED_TABLE` | 법정보호종 표 |

예: `{{BIRD_SPECIES_TABLE}}`, `{{BIRD_RESULT_TEXT}}`

누름틀이나 필드명 방식도 후보다. `평가서샘플/` 의 HWPX 로 시험한 뒤 최종
방식을 확정한다.

## 표 분할

긴 종목록은 하나의 표로 넣지 않는다.

1. 스타일의 `rows_per_page` 로 페이지를 나눈다.
2. 페이지마다 머리글을 반복한다.
3. 페이지별 표 크기와 열 너비를 유지한다.
4. 마지막 페이지의 남는 행은 채우지 않는다.

## 서식

표 스타일은 `config/report_styles.yaml` 에만 정의한다. 코드에서는
`TABLE_SPECIES_LIST` 같은 이름으로 참조한다.

기존 평가서의 정상 표를 템플릿 객체로 복제한 뒤 내용만 바꾸는 방식도
검토 대상이다. 샘플 파일로 두 방식을 비교한 뒤 정한다.

## 이미지

- 셀 크기에 맞추되 원본 비율을 유지한다.
- 그래프 파일명은 `{taxon_code}_{chart_kind}.png` 규칙을 따른다.
- 사진 캡션은 초기 단계에서 파일명을 그대로 쓴다.

## 저장

원본 평가서는 덮어쓰지 않는다. 항상 새 파일로 저장한다.
