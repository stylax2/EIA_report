# 범용 분석항목 카탈로그

> 이 문서는 항목을 **T1/T2/T3 계층**으로 정의한다. 같은 항목을 **분류군별로
> 펼치고 표·그래프 산출 가능성을 판정한 것**은
> [`analysis_items_by_taxon.md`](analysis_items_by_taxon.md) 에 있다.

환경영향평가서 동·식물상 분야는 업체마다 분석항목과 표 구성이 다르다. 이
프로젝트는 특정 평가서 양식을 따라가지 않고, **원자료에서 산출 가능한
항목을 모두 정의해 두고 보고서 양식이 요구하는 것만 골라 쓰는** 방식을
택한다.

따라서 분석항목은 "어느 업체가 쓰느냐"가 아니라 **"원자료가 무엇을
지지하느냐"** 로 계층을 나눈다.

---

## 1. 산출 가능성 계층

| 계층 | 조건 | 성격 |
|---|---|---|
| **T1 공통** | 출현 여부만 있으면 산출 | 모든 분류군에 항상 적용 |
| **T2 분류군 특이** | 마스터DB의 분류군별 속성 컬럼 필요 | 해당 분류군에만 적용 |
| **T3 정량** | 개체수(정수) 필요 | 개체수를 기록한 분류군에만 적용 |

핵심 규칙: **산출할 수 없는 항목은 0이나 공란으로 채우지 않고 "자료 없음"
으로 명시한다.** 개체수가 없는 분류군에 다양도지수를 0으로 적어 넣는 것이
평가서에서 가장 흔한 오류이기 때문이다.

---

## 2. 분류군별 원자료 지지 범위

`datamaster/EIA_가상데이터.xlsx` 의 입력 규칙에서 확인한 실제 값 유형이다.

| 분류군 | 문헌1·2 | 현지조사1·2 | 개체수 | T3 산출 |
|---|---|---|---|---|
| 포유류 | 1 | 조사방법 코드(SI/TR/SC/AU/CT) | ✗ | 불가 |
| 조류 | 1 | 개체수(정수) | ✓ | 가능 |
| 양서류 | 1 | 1 | ✗ | 불가 |
| 파충류 | 1 | 1 | ✗ | 불가 |
| 어류 | 1 | 개체수(정수) | ✓ | 가능 |
| 육상곤충류 | 1 | 1 | ✗ | 불가 |
| 저서성대형무척추동물 | 1 | 개체수(정수) | ✓ | 가능 |
| 관속식물 | 1 | 1 | ✗ | 불가 |

개체수를 기록하는 분류군은 8개 중 3개뿐이다. 나머지 5개 분류군에 대해서는
군집지수를 요구하는 평가서 양식이라도 산출할 수 없으며, 이 경우 조사
설계 단계에서 개체수 기록 여부를 먼저 정해야 한다.

---

## 3. T1 — 공통 분석항목

출현 여부만으로 8개 분류군 모두에서 산출한다.

### T1-01 총 출현종수
문헌·현지를 통합한 중복 제거 종수. 평가서의 가장 기본 수치다.

### T1-02 조사구분별 종수
| 구분 | 정의 |
|---|---|
| 문헌조사 출현종 | 문헌1 또는 문헌2에 기록 |
| 현지조사 출현종 | 현지조사1 또는 현지조사2에 기록 |
| 공통 출현종 | 문헌·현지 모두 기록 |
| 문헌 단독 | 문헌에만 기록(현지 미확인) |
| 현지 단독 | 현지에만 기록(문헌 미기재, 신규 확인종) |

"현지 단독"은 문헌에 없던 종이 확인된 경우로, 평가서 본문에서 별도
서술 대상이 된다.

### T1-03 조사차수별 종수
차수별 출현종수와 **차수 간 신규 출현종**(1차 미확인 → 2차 확인)을 낸다.

### T1-04 분류체계별 구성
문 / 강 / 목 / 과 단위 종수 집계. 과별 종수 상위 항목은 "OO과가 N종으로
가장 다양하게 출현하였다" 형태의 본문 서술로 이어진다.

### T1-05 법정보호종
| 항목 | 근거 | 값 |
|---|---|---|
| 멸종위기야생생물 Ⅰ급 | 야생생물법 | 멸Ⅰ |
| 멸종위기야생생물 Ⅱ급 | 야생생물법 | 멸Ⅱ |
| 천연기념물 | 문화유산법 | O |

종별 목록과 등급별 종수를 함께 낸다. **최종 판정은 사람이 확인한다.**

### T1-06 생태계교란생물
생물다양성법 지정종. 종 목록과 종수.

### T1-07 시·도보호종
마스터DB `abb2` 컬럼. 사업 대상지의 시·도에 해당하는 것만 골라 쓴다.

### T1-08 종목록
과명 · 학명 · 국명 · 조사구분별 출현 표시 · 법정보호종 약어(`abb`)로 구성한
표. 평가서 부록의 핵심 산출물이다.

## 4. T2 — 분류군 특이 분석항목

### T2-조류 도래유형 구성
| 코드 | 유형 |
|---|---|
| R | 텃새 |
| S | 여름철새 |
| W | 겨울철새 |
| P | 나그네새 |
| V | 미조 |

유형별 종수와 비율.

### T2-어류 고유종 · 외래종
- 한국고유종 목록과 고유화빈도(%) = 고유종수 / 전체 출현종수 × 100
- 외래종(도입종) 목록과 종수

### T2-육상곤충류 고유종
한국고유종 목록과 종수.

### T2-저서성대형무척추동물 오수생물지수
마스터DB `saprobic_index_Qi` (1~4). **주의:** 공식 한국오수생물지수(KSI)와
생태점수(ESB)는 지표가중치와 출현량 등급이 추가로 필요한데 현재 마스터DB에
없다. 따라서 이 프로젝트는 개체수 가중 Qi 평균을 **참고값**으로만 산출하고,
KSI/ESB 로 표기하지 않는다. 정식 산출은 지표가중치 컬럼 확보 후로 미룬다.

### T2-관속식물

| 항목 | 내용 |
|---|---|
| 식물구계학적특정종 | Ⅰ~Ⅴ 등급별 종수·목록 |
| 희귀식물 | CR / EN / VU / NT / LC / DD / EW 등급별 종수·목록 |
| 특산식물 | 종수·목록 |
| 귀화식물 | 종수·목록 |
| 귀화율(NR) | 귀화식물종수 / 전체 출현식물종수 × 100 |
| 도시화지수(UI) | 귀화식물종수 / 국내 귀화식물 총종수 × 100 |
| 생활형 | Raunkiaer 생활형별 종수 구성 |

귀화율·도시화지수의 분모는 참조 문헌마다 다르다. 국내 귀화식물 총종수는
`config/analysis.yaml` 에서 설정값으로 관리하고, 산출 결과에 사용한 분모를
함께 표기한다.

## 5. T3 — 정량 분석항목

개체수가 있는 조류 · 어류 · 저서성대형무척추동물에만 적용한다.

### T3-01 개체수 집계
총 개체수, 차수별 개체수.

### T3-02 우점종 · 아우점종
상대풍부도(RA, %) 상위 1위 · 2위 종.

### T3-03 군집지수

| 지수 | 식 |
|---|---|
| 우점도 DI | (n1 + n2) / N |
| 다양도 H' | −Σ(ni/N · ln(ni/N)) |
| 균등도 J' | H' / ln S |
| 풍부도 R1 | (S − 1) / ln N |

S = 종수, N = 총개체수, ni = i종 개체수, n1·n2 = 1·2위 우점종 개체수.

지수는 **차수별로 각각 산출**한다. 차수를 합산한 값은 조사 시기가 다른
자료를 섞으므로 평가서에서 쓰지 않는 것이 일반적이다.

## 6. 보고서 양식과의 연결

업체별 양식 차이는 이 카탈로그를 **선택하는 방식**으로 흡수한다.

```yaml
# 사업별 프로파일 예시
profile: 도로사업_A업체
taxa: [관속식물, 포유류, 조류, 양서류, 파충류, 육상곤충류, 어류, 저서성대형무척추동물]
items:
  - T1-01
  - T1-02
  - T1-05
  - T1-08
  - T2-관속식물.귀화율
  - T3-03
```

프로파일에 없는 항목은 계산하지 않고, 프로파일에 있으나 원자료가 지지하지
않는 항목은 "자료 없음" 사유와 함께 보고한다.
