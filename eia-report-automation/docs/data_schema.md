# 데이터 스키마

조사자료는 Long Data 구조를 우선한다. 한 행이 "특정 조사차수·지점에서
특정 종의 출현 기록" 하나를 나타낸다.

## 조사자료 시트

| 필드 | 자료형 | 필수 | 설명 |
|---|---|---|---|
| 분류군 | 문자열 | O | `src/data/taxonomy.py` 의 국문 명칭 |
| 과명 | 문자열 | O | |
| 국명 | 문자열 | O | 표준종목록 마스터 DB 와 대조 |
| 학명 | 문자열 | O | 표준종목록 마스터 DB 와 대조 |
| 조사구분 | 문자열 | O | `문헌` / `현지` |
| 조사차수 | 정수 | O | 1 부터 |
| 조사일자 | 날짜 | O | |
| 조사지점 | 문자열 | O | 지점 코드 또는 명칭 |
| 출현여부 | 불리언 | O | 체크된 행만 종목록에 들어간다 |
| 개체수 | 정수 | | 다양도 계산에 사용 |
| 법정보호종여부 | 불리언 | | 최종 판정은 사람이 확인 |
| 비고 | 문자열 | | |

필드 구성은 실제 평가서 양식과 `datamaster/EIA_표준종목록_입력용_데이터시트_v6.xlsx`
를 대조해 확정한다.

## 표준종목록 마스터 DB

`datamaster/EIA_표준종목록_마스터DB_통합본_v6.xlsx` 를 국명·학명 검증의
기준표로 쓴다. 조사자료의 종명이 이 표에 없으면 검증 단계에서 경고를
남긴다.

## LLM 전달 페이로드

`src/llm/prompts.py` 의 `SurveyFacts`. 여기에 없는 수치는 생성 문장에
등장할 수 없다.

```json
{
  "taxon": "조류",
  "survey_round": 2,
  "species_count": 35,
  "protected_species_count": 2,
  "dominant_species": ["종A", "종B"],
  "diversity_index": 2.81
}
```
