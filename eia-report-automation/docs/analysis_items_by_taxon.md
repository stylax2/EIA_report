# 분류군별 분석항목과 표·그래프 산출 가능성

`analysis_items.md` 가 항목을 T1/T2/T3 계층으로 정의했다면, 이 문서는 그것을
**분류군별로 펼치고 각 항목을 표로 낼 수 있는지 그래프로 낼 수 있는지**를
판정한다.

판정 근거는 전부 `EIA_가상데이터_v8.xlsx` 실측값이다. 추정하지 않는다.
같은 판정을 `src/analysis/item_catalog.py` 가 코드로 들고 있어 웹 검수
화면의 "분석항목 적용 매트릭스"와 이 문서는 항상 같은 값을 가리킨다.

## 판정 기호

| 기호 | 표 | 그래프 |
|---|---|---|
| ○ | 바로 생성 가능 | 범주 수·분포가 그래프로 의미 있음 |
| △ | 일부 결측 또는 커버리지 부족 | 상위 N개만, 또는 범주가 적어 표가 나음 |
| ✗ | 필요한 자료가 없음 | 그래프로 의미 없음 |

판정 규칙은 기계적이다. 범주 3개 미만이면 표가 낫고(△), 12개를 넘으면
상위 12개만 쓰며(△), 그 사이면 그래프가 적합하다(○).

판정은 **분석 단위(Scope)에 따라 달라진다.** 문헌 단위를 고르면 개체수가
없어 군집지수를 낼 수 없고, 정점 하나만 고르면 지점간 유사도를 낼 수 없다.
아래 표는 각 분류군의 **전체 단위** 기준이다. 단위별 판정은 웹 작업대에서
직접 확인할 수 있다.

전체 26개 항목 × 8개 분류군 × 76개 분석 단위 = **1,000여 건**을 판정한다.

## 9. 산출 불가 항목과 원인

개별 항목이 아니라 **컬럼 하나가 없어서 한 묶음이 통째로 막힌다**는 점이
중요하다.

| 막힌 항목군 | 원인 | 해소 조건 |
|---|---|---|
| ~~지점별 종수·다양도, 지점 간 유사도~~ → **어류·저서무척추는 v8 에서 해소** | 나머지 6개 분류군은 여전히 조사지점 컬럼 없음 | 해당 분류군에도 정점 컬럼 도입 |
| 계절별·월별 변화, 시기별 종조성, 번식기·월동기 구분 | 조사일자 없음 | `조사일자` 추가 |
| 관속식물·양서류·파충류·육상곤충류·포유류의 우점도·다양도·균등도·풍부도 | 개체수 없음 | 해당 분류군 개체수 기록 여부 결정 |
| 어류 내성도·섭식길드, 저서 FFG, 조류 길드 | 마스터DB에 형질 컬럼 없음 | 마스터DB 컬럼 확보 |
| KSI·ESB 정식 수질평가 | 지표가중치·출현량 등급 없음 | 동일 |
| 식생조사, 현존식생도, 녹지자연도 | 조사 자체가 다름 | 별도 자료 설계 |

어류·저서무척추는 v8 에서 정점 컬럼이 생겨 지점별 표를 만들 수 있다.
나머지 6개 분류군은 여전히 `문헌1 · 문헌2 · 현지조사1 · 현지조사2` 넷뿐이라
지점별 항목이 막혀 있고, 조사일자는 전 분류군이 없다.

## 10. 입력양식 확장 제안

위 표의 "해소 조건"을 실제 컬럼으로 옮긴 것이다. 우선순위 순.

### 1순위 — 조사지점 (어류·저서무척추 v8 적용 완료)

컬럼 확장 방식을 택했다. 입력은 사람이 하고 변환은 프로그램이 하므로,
입력 편의를 우선하고 로더가 컬럼을 해석하게 하는 편이 낫다.

```
현지조사1  →  현지조사1_St1 … 현지조사1_St5
```

정점 수는 `TaxonSpec.stations` 로 분류군마다 다르게 둘 수 있다. 나머지
6개 분류군에도 같은 방식으로 넣을 수 있으나, 육상 분류군은 정점보다
조사구역·노선 개념이 맞을 수 있어 조사 설계와 함께 정해야 한다.

### 2순위 — 조사일자
차수만으로는 계절 서술을 할 수 없다. 회차별 조사일자를 별도 시트
(`조사개요`)에 두면 종 시트를 건드리지 않아도 된다.

### 3순위 — 개체수 확대
현재 3개 분류군만 개체수를 기록한다. 나머지 5개 분류군의 군집지수 요구
여부는 조사 설계 단계의 결정 사항이다. 기록하지 않기로 하면 그 자체를
문서화해 "산출 불가" 사유로 쓴다.

### 4순위 — 마스터DB 형질 컬럼
어류 내성도·섭식길드, 저서 FFG·지표가중치, 조류 길드. 확보하면 T2 항목이
분류군마다 2~3개씩 늘어난다.
